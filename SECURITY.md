# Security

If you discover a security vulnerability in this project, please disclose it responsibly.

- Do not create a public issue for sensitive vulnerabilities.
- Contact the maintainer: security@watucredit.local (replace with real contact in production) or open a private channel.

Security hygiene recommendations included in this repo:

- Pre-commit hooks to help prevent committing .env and private key files (see `.githooks/`).
- Do not commit real credentials; keep `.env` out of source control.
- Rotate any secrets that may have been accidentally exposed.
